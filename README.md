# BusAlert — 경기도 버스 이동 리스크 AI 안내 MVP

## 한 줄 소개

경기도 버스 공공데이터를 활용해 교통 취약지역 이용자에게 **버스 도착·혼잡·대기 위험과 맞춤 알림**을 설명하는 Streamlit 기반 AI MVP입니다.

## 문제 정의

교통 취약지역 또는 버스정보 접근성이 낮은 정류장 이용자는 단순 도착 예정시간만으로는 실제 이동 위험을 판단하기 어렵습니다. 특히 고령자, 학생, 보호자, 야간 이용자는 다음 문제를 겪을 수 있습니다.

- 배차 간격이 불안정해 정류장에서 오래 기다림
- 혼잡 또는 지연 가능성을 출발 전에 이해하기 어려움
- 비·눈·야간처럼 위험이 커지는 상황에서 대체 행동을 선택하기 어려움
- 정책 담당자는 어떤 노선에 우선 대응해야 하는지 설명 가능한 근거가 부족함

## 주요 사용자

1. 경기도 내 버스 이용자
2. 고령자·학생 등 교통 취약계층
3. 보호자 또는 돌봄 담당자
4. 정류장 안내 인프라가 부족한 지역 주민
5. 대중교통 정책·운영 담당자

## 핵심 기능

- 노선별 평균 이용객, 배차 변동계수(CV), 위험도 점수 기반 우선순위 산출
- 정류장 수와 CV를 결합한 정보 접근 취약성 프록시 계산
- 사용자 유형·시간대·우려사항에 따른 AI 이동 리스크 설명
- 수요 증가율과 예측 기간을 반영한 미래 혼잡·이용 불편 위험 시뮬레이션
- 지도 기반 노선 시각화
- 심사위원용 데모 설명 및 분석 결과 CSV/HTML 다운로드
- API 키가 없어도 실행 가능한 mock AI 분석 모드

## 활용 공공데이터

현재 MVP는 저장소의 `최종_마스터_테이블.csv` 샘플 데이터를 사용합니다. 실제 서비스화 단계에서는 다음 공공데이터 후보와 연결합니다.

1. **경기데이터드림**
   - 경기도 버스 노선 정보
   - 경기도 버스 정류소 정보
   - 지역·행정동 단위 교통 취약 관련 데이터
2. **공공데이터포털**
   - 버스 도착 정보 API
   - 노선 정보 API
   - 정류소 정보 API
3. **경기도 버스정보시스템/BMS 연계 후보**
   - 실시간 버스 위치
   - 배차 간격
   - 도착 예측
4. **보강 데이터 후보**
   - 고령인구, 장애인 시설, 학교, 병원, 대중교통 접근성 지표

실제 API 연결이 필요한 부분은 `app_busAlert.py`의 데이터 로딩 함수와 분석 함수 구조를 교체해 확장할 수 있습니다. API 키나 인증정보는 코드에 넣지 않고 환경변수로 관리해야 합니다.

## AI 활용 방식

이 프로젝트에서 AI는 장식용 챗봇이 아니라 사용자의 이동 의사결정을 돕는 설명 계층입니다.

- 수요, CV, 정류장 기반 취약성 점수를 결합해 이동 리스크를 요약
- 고령자, 학생, 보호자, 정책 담당자 등 사용자 유형별 안내 문구 생성
- 시간대나 악천후 상황에 따라 알림 우선순위 추천
- 정책 담당자에게 증차·배차 조정·안내 인프라 개선 후보를 설명
- `ANTHROPIC_API_KEY`가 없으면 `mock_ai_analysis()` 기반 데모 모드로 실행
- 추후 실제 LLM API 사용 시 `ask_real_llm()` 함수로 교체·확장

## 실행 방법

### 1. 가상환경 생성 및 패키지 설치

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Streamlit 앱 실행

```bash
streamlit run app_busAlert.py
```

브라우저가 열리면 사이드바에서 사용자 유형, 관심 노선, 시간대, 분석 가중치를 조정해 데모를 확인합니다.

## 환경변수 설정 방법

기본 실행에는 API 키가 필요하지 않습니다. 실제 LLM API를 사용하려면 `.env.example`을 참고해 환경변수를 설정합니다.

```bash
cp .env.example .env
export ANTHROPIC_API_KEY="your-real-api-key"
export ANTHROPIC_MODEL="claude-sonnet-4-20250514"
streamlit run app_busAlert.py
```

주의: `.env`에는 실제 인증정보가 들어갈 수 있으므로 Git에 커밋하지 않아야 합니다.

## 데모 시나리오

1. `streamlit run app_busAlert.py`로 앱을 실행합니다.
2. 사이드바에서 사용자 유형을 `고령자` 또는 `보호자`로 선택합니다.
3. 시간대를 `퇴근 시간대` 또는 `비/눈 등 악천후`로 바꿉니다.
4. 관심 노선을 자동 또는 특정 노선으로 선택합니다.
5. 상단 AI 알림 카드에서 위험 등급, 근거, 추천 알림 문구를 확인합니다.
6. `현황 진단` 탭에서 노선별 우선순위와 ML 피처 중요도를 확인합니다.
7. `미래 예측` 탭에서 수요 증가율을 바꿔 미래 위험 변화를 설명합니다.
8. `AI 분석` 탭에서 심사위원 질문에 대한 mock AI 요약 또는 실제 LLM 응답을 생성합니다.

## 현재 한계

- 현재 데이터는 샘플 CSV이므로 실시간 버스 도착정보를 직접 조회하지 않습니다.
- 정류장 수와 CV를 활용한 접근성 점수는 MVP용 프록시이며 실제 취약성 지표가 아닙니다.
- 샘플 노선 수가 제한적이어서 ML 모델 성능은 서비스 검증 지표가 아니라 데모 설명용입니다.
- 혼잡도는 실제 차내 혼잡 센서 또는 승하차 시간대 데이터가 추가되어야 정확해집니다.
- LLM API는 선택 사항이며 기본값은 mock AI 분석입니다.

## 향후 개선 방향

1. 공공데이터포털/경기데이터드림 API를 통한 실시간 도착·노선·정류소 정보 연동
2. 시간대별 승하차, 지연, 기상, 행사 데이터를 결합한 혼잡 예측 모델 고도화
3. 행정동별 고령인구·장애인 시설·학교·병원 접근성 데이터 결합
4. 카카오톡·문자·앱 푸시 기반 보호자 공유 알림
5. 정류장 전광판 또는 음성 안내와 연계한 정보 접근성 강화
6. 데이터 품질 검증 파이프라인 구축
7. 개인정보 최소 수집, 사용자 동의, 알림 로그 보관 정책 수립

## 경진대회 제출 시 강조 포인트

- **사회문제**: 교통 취약지역 이용자의 긴 대기, 혼잡, 정보 접근 불균형 완화
- **공공데이터 필요성**: 노선, 정류장, 도착정보, 행정동 취약성 데이터가 있어야 지역별 이동 위험을 계산 가능
- **AI 필요성**: 숫자 지표를 사용자 유형별 행동 안내와 정책 우선순위 설명으로 변환
- **MVP 구현 범위**: 샘플 데이터 로딩, 위험 점수 계산, 미래 위험 시뮬레이션, mock AI 안내, 지도/다운로드 제공
- **서비스화 필요 요소**: 실시간 API, 더 많은 기간의 운행 데이터, 교통약자 지표, 데이터 품질 관리, 개인정보·보안 정책
